## 实际问题与反例

后段缺口污染早段触发：F11原有逻辑按整个搜索窗口检查连续性，即使选中事件早已确认仍被后段间隙否决。改为校核至所选确认样本的必要历史。保留前段缺口、第N次事件、跨缺口确认和末端未确认反例。

离线双击复位：零延迟内嵌数据加载在每次pointerup重绘SVG，破坏后续dblclick的相同目标。无实际平移/框选时不再重建SVG；三处查看器的滚轮、框选、拖动、双击均由真实Chromium事件回归。

畸形批次请求：非对象JSON、缺少action、不允许参数和无效任务被明确400/404拒绝，不清空另一单次已加载结果。ZIP采用原子写入且冻结复用，重复下载内容一致。

F06冻结反例：最初把“冻结”一律预判为阶跃不合格，实际该240ms位置并未违反配置响应/上升限值；保留其阶跃PASS，不事后收紧阈值。跨总分表关系断言独立检出101.52kW残差。首轮预期修订日志完整保留。

F10异步交流反例：分段线性重构本身不能担保亚伏级误差。新增显式绝对误差预算与三态区间判定；工程示例预算不是校准结论，保留INCONCLUSIVE，而不是把阈值改到PASS。
