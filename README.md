# ESS WaveTest 1.3.0

**文件夹批处理 · 分层耦合波形 · 工作台和离线报告均可缩放**

这是离线工程验证版，不是已完成厂家/现场认证的生产放行工具。包含可运行单文件程序、完整源码、85组COMTRADE录波（23基础 + 12复杂 + 32抗噪 + 18分层耦合）、用例、故障注入真值、报告及图文指南。所有示例阈值都是教学工程配置，不是标准原文。

## 先确认运行的是新版

需要Python 3.10及以上；应用和标准库自测不依赖第三方Python库、不联网。
Windows：解压到新目录后双击 `start.bat`。macOS / Linux：`python3 ESS_WaveTest.pyz gui`。

```sh
python ESS_WaveTest.pyz --version
# 必须显示 1.3.0
python ESS_WaveTest.pyz gui --port 8765
```

地址 `http://127.0.0.1:8765`。旧服务仍占端口时先关闭旧服务，或使用 `--port 8766`；必要时在浏览器按Ctrl+F5刷新。不要用旧pyz运行新目录。源码入口：`python launch.py gui`。

## 1. 文件夹批量验收

进入 **04 文件夹批处理**，选择 `examples/field`，勾选“包含子目录”，用例模式选“每组使用同目录同名JSON”。点击“扫描与检查配对”，然后“开始批量执行”。18组模型工况的实际验收应为：**4组PASS、9组FAIL、5组INCONCLUSIVE**；这是有意注入故障后的正确输出，不是18组设备都通过。

```text
客户批次/
  一号PCS/录波001.cfg
  一号PCS/录波001.dat
  一号PCS/录波001.json
  二号PCS/录波001.cfg
  二号PCS/录波001.dat
  二号PCS/录波001.json
```

同目录同名CFG/DAT配对，不同子目录的同名文件不串组；扩展名大小写不敏感，冲突时拒绝猜测。也可选择“统一用例”：先在“用例与断言”确认JSON，扫描时冻结这一配置快照。后续修改编辑器不会偷偷改变本批次。

每组独立解析、判定、保存报告，坏文件不阻断其他组。缺CFG、缺DAT、缺同名JSON、同目录大小写重名、上传截断均显示错误，孤立DAT不被跳过。支持进度、筛选、取消剩余任务、打开已完成结果、导出ZIP汇总包。取消在当前记录执行完后生效；未执行不算通过。

结果ZIP含 `index.html`、`summary.json`、`summary.csv` 和每组HTML/JSON/CSV/JUnit。解压后在本机浏览器打开index。源CFG/DAT不重复拷入报告包，须单独保留。

浏览器单组上传128 MiB、每批最多2000组/10000文件、所选源文件总量2 GiB；会话保留最近3批，累计源文件预算2 GiB。逐组解码，但内存仍取决于最大单组数据，不是固定内存或磁盘配额。服务关闭清理临时目录，**没有跨重启断点续跑**；请及时导出。CLI读取本地源文件，不受浏览器上传128 MiB限制；解析器DAT512 MiB、解码数组预算512 MiB仍生效。

## 2. 三处波形都能放大缩小

**录波预览、单次/批量结果详情、导出的离线HTML报告**均有显眼的“＋放大 / －缩小”，并支持滚轮锚点缩放、拖动平移、Shift框选、双击/全览复位、精确起止秒、概览导航，以及“幅值＋ / 幅值－ / 幅值复位”。

在“录波与通道”选择F05，载入演示，预览D5，定位 **6.558–6.563秒**，可查看1 ms保护脉冲；A11定位 **6.40–6.83秒** 查看不平衡跌落中的一相瞬时波形。已有原始/处理/候选图层不删除、不在缩放时重新滤波。

工作台每次缩放重新读取局部原始采样。离线报告在导出时嵌入完整证据窗口的原始/处理点，总预算60万点；放大先切片再抽稀，不是放大旧缩略图。预算不足或历史报告未找到哈希匹配源文件时，显式标记“证据摘要，不能恢复未保存采样”，仍可缩放，但须回工作台查完整原始录波。摘要不能伪装为原始分辨率。

请把HTML下载/解压后在系统浏览器打开；聊天预览器、PDF和图片不能承载JavaScript交互。PDF/PNG是说明/截图，不是可缩放波形浏览器。

## 3. 这次的复杂波形

18组新工况位于 `examples/field` 三层目录，多数24模拟+104数字、10秒、20001采样；F17为128模拟+384数字，F10为2000/8000/2000 Hz三段采样率与通道偏移。

模型先生成两台PCS不同延迟/阻尼的闭环状态、指令斜率限制、P/Q电流容量约束，再耦合直流电容能量与电池RC模型，最后叠加测量与采集链。包含六段充放电指令、不平衡跌落、相位跳变、频率偏移、谐波、恢复振铃、相关/独立噪声、共模尖峰、量化、遥测冻结、单表漂移、丢点和数字保护/握手。

- F06：遥测冻结240 ms，单通道阶跃指标仍可满足；总表减两分表的残差达到101.52 kW，关系断言检出。
- F08：多通道同步尖峰甚至保持总分表关系一致；仍由原始/处理峰值冲突判待复核，不能自动认定采集噪声。
- F15：禁用限流后，模型电流包络最大212.31 A，超过161 A示例上限，判FAIL。
- F16：冻结、丢确认、1 ms保护脉冲、共模尖峰同时存在；分别保留失败和待复核原因。

每组 `*.truth.json` 保存种子、模型参数、事件、潜在无噪状态抽样、文件哈希与预期断言。真值只供回归对照，判定引擎不读取真值文件。不把预期FAIL反转成验收PASS。

**这些是物理启发的降阶合成模型，不是客户现场录波，也不是完整EMT/HIL模型。** 未重建开关器件、完整PLL/电流环、实际站内拓扑和厂家保护控制。复杂程度提升不等于已证明现场真实性；现场定参需要已标注真实健康/故障/歧义录波。采样噪声不从名称自动归因，通道名不代表保护合法性。

## 4. 新算法和实际修复

新增 `analog_relation`，显式定义 `measured - (offset + Σ gain × reference)`。所有信号先经过已有工程换算和skew对齐，用各通道时间戳并集检查，不能漏掉只出现在参考通道上的尖峰。按分段线性模型精确累计绝对残差出带时长；原始硬残差不滤波。缺点/缺口不插值跨越。

可预声明 `alignment_error_bound`，用于已审核的绝对对齐误差预算；不自动估计，也不代表计量校准。区间上下界能证明才PASS/FAIL，否则INCONCLUSIVE。F10快速交流信号的误差预算大于容差，保留待复核，不用补偿偷偷放宽阈值。该功能目前通过JSON配置，关系残差详见指标/JSON证据，图主要展示被测通道，不声明多参考残差叠加界面。

修复实际复现的问题：后段采样缺口不再污染已完整观察的早段触发；仍验证所选触发之前和确认阶段的必要历史，不能跳过前段缺口冒充第N次触发。离线报告快速重绘不再破坏双击复位。批量接口拒绝畸形JSON并隔离单次结果，ZIP并发导出不覆盖正在读取的档案。

## 命令行

```sh
# 文件夹真实验收：保持实际PASS/FAIL，非“预期回归通过”
python ESS_WaveTest.pyz batch --directory "examples/field" --recursive --sibling-cases --out "my_batch"
# 同一已审核用例用于整目录
python ESS_WaveTest.pyz batch --directory "D:/FAT" --recursive --case "D:/rules/suite.json" --out "D:/reports"
# 重新生成合成录波与真值
python ESS_WaveTest.pyz generate-field --out regenerated_field --seed 20261011
# 预期结果回归：回归PASS不表示设备均合格
python ESS_WaveTest.pyz batch --manifest examples/field/manifest.json --out field_regression
python run_selftests.py
python tools/verify_field.py
python tools/build_zipapp.py
python tools/release_smoke_v13.py
```

单文件和目录验收退出码0=PASS、1=FAIL、2=ERROR、3=INCONCLUSIVE。CLI目录输出每组报告与summary.json；GUI额外打包CSV/HTML批次索引和ZIP。不提供跨文件时钟自动对齐、在线设备控制、文件监听、CFF/厂家私有扩展、完整谐波/序分量/三相功率重建或标准认证库。
